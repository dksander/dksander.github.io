The other day I got an email I didn't quite understand, so maybe this can be useful for others:

![The "Your free Copilot access is ready" email from GitHub](/assets/free-copilot-email.png)

I cancelled my GitHub Copilot subscription about a month ago. (And in my earlier posts, I've been complaining about what I suddenly miss.) And then, bam – several of those features were back. And for FREE?!

I went into full-blown Googling mode to figure out why I had gotten it, before it dawned on me that it's a very limited set of functionality. Deep down, it's really just an ad for why you should buy GitHub Copilot. 😉

I really should learn to read the fine print before I start getting excited:

![What's included in the free Copilot plan: 2,000 code completions every month and Copilot Chat](/assets/copilot-free-whats-included.png)

But so far, it's actually nice to get something as simple as the automatic descriptions on commits back:

![The sparkle button next to the commit message field in VS Code](/assets/copilot-commit-button.png)

One click on the button, and Copilot writes the commit message for me:

![A generated commit message in VS Code](/assets/copilot-commit-message.png)

Simple, but for most developers who are too lazy to write a sensible commit message themselves, it's really helpful.

Even if it's an "ad", it's great to get to try some of the things I've been missing – so now we'll see how long it lasts 😊
